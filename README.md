# Pair-programming-Project-Roomies
A roommate organizer that brings shared purchases, household supplies, and chores into one place, so everyone can see what they owe and what they are responsible for.

## Current Features
- Add roommates to a household.
- Enter a shared purchase and identify who paid.
- Split the cost equally among roommates.
- Display how much each roommate owes or is owed.
- Check for blank or duplicate names and invalid numeric inputs.

## Planned Features
- Purchase history and Pandas summary tables.
- Shared household supply tracking.
- Chore selection and fair assignments.

## How to Run
Open Pair_programming_Project_Roomies.ipynb in Google Colab. Run the code cells from top to bottom and answer the prompts.

## Project Status
This is our starting version. It uses Python classes, lists, loops, and input validation. Additional features will be added as we develop the project.
